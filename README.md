本專案專為進金生能源內部**光伏維運團隊、案場主任與專業電氣工程師**設計。打破傳統「光電維運純粹是擦板打掃」的經驗主義誤解，嚴格依據 **20261027 太陽光電設置乙級技術士回訓教材、台電配電處最新併網技術規範、標檢局憑證要點與現場演講錄音（共 250 分鐘）**，運用**麥肯錫金字塔原理（Pyramid Principle）**重新提煉結構化知識：

3. **向量工程圖表重置與實體講義圖冊對照**：

## ⌨️ 簡報快捷鍵一覽

在任何簡報頁面（`courses/*.html`）中，工程師可使用以下鍵盤快捷鍵：

| 快捷鍵 | 功能說明 | 應用情境 |
| :---: | :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> | 下一頁投影片 | 循序講解培訓內容 |
| <kbd>←</kbd> / <kbd>Backspace</kbd> | 上一頁投影片 | 倒退複習關鍵重點 |
| <kbd>N</kbd> | **呼出 / 關閉 講者備忘錄抽屜 (Speaker Notes)** | 查看麥肯錫三段式講稿與實務現場補充 |
| <kbd>G</kbd> | **投影片總覽網格導航 (Grid Overview)** | 快速檢視全 20 頁並跳轉至指定主題 |
| <kbd>F</kbd> | **切換全螢幕模式 (Fullscreen)** | 會議室投影、晨會技術交底或外訓簡報 |
| <kbd>P</kbd> | **一鍵列印 / 匯出 16:9 顧問 PDF 備忘錄** | 自動隱藏工具列，以純淨 16:9 比例匯出 |
| <kbd>Esc</kbd> | 關閉燈箱或關閉總覽網格 | 返回正常簡報閱讀模式 |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | 聚焦全域搜尋框 (首頁) | 快速啟動全庫搜尋 |
