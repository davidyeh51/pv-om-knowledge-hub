## 📌 專案核心定位

本專案專為進金生能源內部**光伏維運團隊、案場主任與專業電氣工程師**設計。打破傳統「光電維運純粹是擦板打掃」的經驗主義誤解，嚴格依據 **20261027 太陽光電設置乙級技術士回訓教材、台電最新併聯技術要點與現場演講錄音**，運用**麥肯錫金字塔原理（Pyramid Principle）**重新提煉結構化知識：

1. **結論先行（Action Titles）**：每頁簡報標題即為該工程主題之實質行動結論，拒絕空泛分類詞。
2. **三核心要素剖析**：
   - 📌 本章要解決的問題／核心論點
   - 💡 1–3 個最值得記住的亮點（獨特觀點、反直覺之處、關鍵數據或案例）
   - 🎯 一句話總結
3. **向量工程圖表重置與 66 張實體講義原圖對照**：
   - 包含台電三相平衡容量矩陣表、逆變器 300 秒狀態機流程圖、STC 照度鉗表 30% 清洗模型、半切 vs 全片阻抗對比、MC4 端子防燒燬與負極 -199V 防觸電 SOP。
   - 每頁均配備高解析實體講義縮圖，點擊即可開啟燈箱放大檢視。
4. **全域與頁內即時關鍵字檢索引擎**：
   - 支援模糊比對、多關鍵字交集、標籤快篩與匹配詞高亮（`<mark>`），點擊一鍵直達特定簡報投影片（如 `#s8`）。
5. **講者備忘錄模式（按 `N` 鍵呼出）**：
   - 內建三段式演講講稿（① 本頁核心結論、② 補充說明與現場數據、③ 下一頁轉場提示），完全融入葉大衛講師 62 分鐘現場實戰心法。

| :---: | :--- | :---: | :--- |
| **模組一** | **光電基礎與發電物理特性** | Slide 01-05 | 電壓在日照 &gt;350 W/m² 即飽和（受通風散熱負相關影響）；電流與日照呈嚴格線性正比。風雨球場無風效率低 5%~10%。半切晶片集電密度提升，電阻熱損耗降為四分之一 ($P=I^2R$)。 |

## 🛠️ 資料擴充架構指南（三步驟快速新增課程）

本知識庫採用**數據驅動（Data-Driven）的模組化架構**：

```
pv-om-knowledge-hub/
├── index.html                   # 知識庫入口主頁（課程地圖 + 全域搜尋）
├── generate_deck.py             # 旗艦簡報生成器
├── generate_index.py            # 主頁生成器
├── courses/
│   ├── pv-om-fundamentals.html  # 旗艦回訓 16:9 簡報（20 Slides）
│   └── [未來課程].html          # 擴充課程簡報
├── assets/
│   ├── css/
│   │   ├── style.css            # 麥肯錫入口首頁樣式
│   │   └── deck.css             # 16:9 簡報樣式與列印樣式
│   ├── js/
│   │   ├── search.js            # 全文檢索引擎與高亮模組
│   │   └── deck.js              # 簡報互動控制器 (鍵盤/講稿/燈箱/總覽)
│   └── images/
│       └── slides/              # 66 張高清原廠講義圖冊 (slide_01.jpg ~ slide_66.jpg)
├── data/
│   ├── courses.json             # 課程目錄與擴充中繼資料
│   └── search-index.json        # 全域搜尋索引
└── docs/
    └── EXPANSION.md             # 擴充 SOP 指南
```

### 擴充步驟：

1. **建立新課程簡報**：
   在 `courses/` 資料夾建立新檔案（例如 `courses/pv-bess-scada.html`），採用標準 16:9 結構與金字塔三段式講稿。
2. **登記至中央目錄**：
   在 `data/courses.json` 的 `courses` 清單中加入新課程配置（包含 ID、標題、講師、摘要、標籤等）。
3. **更新搜尋索引並推播**：
   在 `data/search-index.json` 加入新簡報之投影片索引關鍵字，執行 `git add . && git commit && git push`，GitHub Pages 即可完成全域無縫升級！

## ⌨️ 簡報快捷鍵一覽

- `→` / `Space` / `PageDown`：下一頁
- `←` / `Backspace` / `PageUp`：上一頁
- `N`：開啟／關閉麥肯錫三段式講者備忘錄
- `G`：開啟／關閉 20 頁投影片總覽導航網格
- `F`：切換全螢幕模式
- `P`：匯出／列印為高解析 PDF 文件
- `Ctrl + K` 或 `/`：快速聚焦全域檢索輸入框
- `Esc`：關閉所有彈出視窗（講稿、總覽、原圖放大燈箱）
