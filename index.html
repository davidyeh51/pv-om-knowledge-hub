📌 核心論點 (Core Thesis)
光伏維運的核心不是被動擦板，而是解耦發電物理參數、防範熱斑起火、嚴格遵循接頭工藝與精準匹配台電電網併聯特性。
  • 物理解耦：日照定電流、通風散熱定電壓；模組更換嚴格匹配電流差值在 1A 以內。
  • 科學清洗：以共平面照度鉗表修正值衰退 30% 為觸發標準，杜絕歷史 PR 統計誤差。
  • 工安死角：單斷正極組串負極對地仍帶 -199V 高壓，正負雙斷、驗電歸零方可施作。
  • 台電規範：依台電函稿 1088051755 號處置高電壓平頭截斷，嚴守單相 20kVA 與三相容量差 5kVA。

🛠 知識庫資料擴充架構（三步驟快速新增課程）

本專案採用數據驅動 (Data-Driven) 的靜態生成架構，各課程維持獨立 HTML 簡報，主頁與全域搜尋引擎自動連動，內部工程師新增課程只需三步驟：

1

在 courses/ 目錄建立新課程 HTML 簡報（如 courses/pv-bess-scada.html），遵循金字塔原理（問題、3大亮點、總結）與 16:9 版型。
courses/ └── pv-bess-scada.html
2
登記至中央目錄
在 data/courses.json 的 courses 陣列加入新課程中繼資料（標題、講師、摘要、核心論點與標籤）。
{ "id": "pv-bess-scada", "title": "PV-BESS 智慧告警", "status": "ready" }
3
更新檢索索引並發布
將新章節投影片條目同步至 data/search-index.json，執行 git commit 並推送至 GitHub，GitHub Pages 自動即刻完成全域發布！
